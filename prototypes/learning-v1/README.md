# 小智学堂交互原型 v1

面向5岁儿童，240×320屏幕，三键交互。此目录是独立网页原型，不参与固件构建。

打开 index.html，或在本目录运行 `python3 -m http.server 8765` 后访问 http://localhost:8765。

## 已实现

- 首页：英语、古诗两个入口。
- 英语：4个示例词，浏览器示范朗读；最后一词向下进入听音找图。
- 听音找图：4轮、两选一、重试和继续流程。
- 古诗：《静夜思》逐句朗读、隐藏正文的背诵提示、重学。
- 上下选择／换内容，中间确认／听读，长按中间返回，上下长按调音量。
- 键盘上下、Enter、Esc；保存单词和诗句位置。

## 已做检查

浏览器验证首页进入英语、翻至小游戏、答案反馈、进入古诗、切换背诵模式；检查桌面布局。

## 设计与实现边界

表情图形暂代插画；语音由浏览器 SpeechSynthesis 提供，需系统具备对应声音，不保证离线。
没有录音、发音评分、云端连接或固件联动。词库和诗库只提供流程样本。
后续应补充每句专属意境图、本地音频、完整内容、学习记录和实机按键验证。
